# STEP Academy

教育を中心にした、部門向け学習ポータルの比較サンプルです。`index.html` をブラウザで直接開いて利用できます。外部ライブラリ・通信・ビルドは不要です。

- `index.html`: コース一覧、学習ワークスペース、使い方のダイアログ。
- `styles.css`: コバルト色、水平ナビゲーション、順序を示す経路図、レスポンシブ表示。
- `app.js`: 3コース・各3レッスンの本文と確認問題、検索、前後移動、学習記録。

コースを選び、本文を読んで3択問題に回答します。正解するとレッスンが完了し、進捗が更新されます。誤答では完了しません。レッスンは一覧から自由に見直せます。「学習をつづける」は最後に開いたレッスンを開きます。

進捗は `tsumugu-sample-academy-v1` のキーで、このブラウザの localStorage に保存します。保存を利用できない場合は注意を表示し、開いている間の利用を継続します。他の利用者との進捗共有や認証は行いません。

本文・確認問題・所要時間は体験用のサンプルです。実際の社内資料の内容や、実際の読了・視聴を証明するものではありません。元の資料タイトル・URLは `../../portal/data.js` を参照します。リンク未設定の資料には遷移先を作らず、その旨を表示します。

サンプル一覧は `../../../samples.html`、元のポータルは `../../../index.html` です。
