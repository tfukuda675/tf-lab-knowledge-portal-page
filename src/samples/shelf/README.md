# SHELF — 知識の本棚

テーマ別のコレクションから資料を眺めて探す、図書館型のポータルサンプルです。

- `index.html`: 本棚、カテゴリ、検索、資料詳細。
- `styles.css`: プラム色のカタログ、コレクションの本の図形、レスポンシブ表示。
- `app.js`: 検索・種類とカテゴリの絞り込み、表示切替、並べ替え、あとで読む。

共通の `../../portal/data.js` と `model.js` を読み取り専用で利用します。`index.html` を直接開けます。保存キーは `tsumugu-sample-shelf-v1`。あとで読むはこのブラウザ内に保存され、既存ポータルや他サンプルの保存内容とは別です。外部通信やライブラリの読み込みはありません。サンプル資料はリンク未設定を明示し、公開参考資料だけ実URLを開けます。
