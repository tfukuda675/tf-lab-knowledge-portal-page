# PLAYBOOK — しごとの道しるべ

業務手順を探し、その場でチェックリストに沿って進めるためのポータルサンプルです。

- `index.html`: 検索、業務カテゴリ、手順一覧、実行チェックリストの画面。
- `styles.css`: ネイビーと白の業務ワークベンチ。390px幅にも対応します。
- `app.js`: 6件のサンプル手順、検索、カテゴリ絞り込み、手順選択、進捗の保存。

`index.html` を直接開けます。外部ライブラリやビルドは不要です。手順は説明用サンプルで、実際の社内資料へのリンクは未設定です。チェックは `tsumugu-sample-playbook-v1` としてブラウザの localStorage に保存され、他の利用者とは共有されません。保存できない場合は一時的に画面内で利用できます。実際に業務を実施したことや、承認を受けたことを証明するものではありません。
