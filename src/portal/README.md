# 部門ナレッジポータル

- `data.js`: カテゴリ、サンプル資料、順序付き学習コース。
- `model.js`: 検索、URL 検証、保存データの検証を行う純粋関数。
- `catalog.js`: JSONカタログの検証・正規化、配布用スクリプト生成、進捗の引き継ぎ判定。
- `app.js`: DOM 描画、検索、登録、ブックマーク、学習進捗の保存、JSON入出力。
- `styles.css`: デスクトップ・モバイル表示とダイアログのスタイル。

ビルド・外部ライブラリ・実行時の外部通信は不要です。通常のスクリプトとして読み込むため `file://` からも利用できます。

JSONはファイル選択で明示的に読み込みます。検証・プレビュー後の適用で、ブラウザ内のカタログを置き換えます。起動時は `localStorage` の有効な `catalog` を配置ファイルより優先し、その後に追加資料・コースと個人の状態を復元します。「配置ファイルのデータに戻す」は優先カタログと追加分を取り除きます。
