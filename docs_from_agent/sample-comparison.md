# 3つの部門ポータルの比較と使い方

入口は [`samples.html`](../samples.html) です。各サンプルはビルドせずブラウザで直接開けます。既存の「つむぐ」を含め、用途と情報の見せ方を比較するための試作です。

| サンプル | 目的・構成 | 基本操作 |
| --- | --- | --- |
| PLAYBOOK / しごとの道しるべ | 業務を進める。ネイビーの業務一覧と実行チェックリスト | 作業を検索・絞り込み、手順を選んで完了にチェック |
| STEP Academy | 順序に沿って学ぶ。コース一覧と教材・確認問題の学習画面 | コースを選び、教材と問題を確認して次のステップへ |
| SHELF / 知識の本棚 | 知識を眺めて探す。テーマ別コレクションと資料カタログ | テーマや検索で絞り込み、資料詳細を開き、しおりであとで読むに保存 |

PLAYBOOKは繰り返し行う業務の手順確認、STEP Academyは入門やオンボーディングの学習導線、SHELFは種類の異なる資料を広く見渡す入口を試す構成です。配色だけでなく、ナビゲーション・情報配置・操作の目的を変えています。

## 保存と共通データ

- PLAYBOOK: `tsumugu-sample-playbook-v1`
- STEP Academy: `tsumugu-sample-academy-v1`
- SHELF: `tsumugu-sample-shelf-v1`

進捗や保存状態は各ブラウザの `localStorage` に保存し、サンプル間や既存「つむぐ」とは分離します。保存できない場合も一時的な操作を続けられます。共通資料データを読み取り専用で参照しますが、「つむぐ」で追加した資料・作成コースはサンプルへ自動反映しません。

初期資料や手順・教材の内容は掲載例です。実際の社内資料へアクセスするにはデータの差し替えが必要です。未設定リンクはサンプルである旨を表示し、架空の社内URLには遷移しません。公開参考資料だけ実際のURLを持っています。

本サンプルには認証・部門全員のデータ共有・受講者集計・カテゴリ管理画面を含みません。チェックや確認問題は本人の進行を補助するもので、読了や視聴の自動証明ではありません。

- 比較ページ：3案へのリンクとモバイル表示。
- PLAYBOOK：検索、カテゴリ、ショートカット、チェック状態の保存・復元、破損した保存データへの対応。
- STEP Academy：検索、確認問題の誤答・正答判定、次の教材への移動、進捗の復元、モバイル表示、破損した保存データへの対応。
- SHELF：検索、コレクション、資料種別、一覧表示、資料詳細、あとで読むの保存・復元、モバイル表示、破損した保存データへの対応。
