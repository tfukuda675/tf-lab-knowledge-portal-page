# 動作確認

- `catalog-test.html`: JSONカタログの検証・正規化・安全な配置用JS生成・進捗の引き継ぎを確認します。
- `catalog-flow.html`: JSON書き出し、ファイル選択からの検証・プレビュー・適用、再読み込み、配置ファイルへの復帰を確認します。保存状態を書き換えるため専用プロファイルで実行してください。
- `sample-portals.html`: 3案の比較ページ、手順チェック、学習問題、あとで読む、検索・保存・狭幅表示を検証します。各サンプルの保存状態を消すため、専用の Chrome テストプロファイルで実行してください。
- `course-flow.html`: コース作成、資料の並べ替え、確認問題の正誤判定、本人チェック、順序・進捗の保存を検証します。保存内容を書き換えるため、専用の Chrome テストプロファイルで同一オリジンを許可して実行してください。
- `model-test.html`: URL 検証、検索、複合絞り込み、保存データ検証、コースの参照整合性。ブラウザで直接開くと結果を表示します。
- `browser-smoke.html`: iframe 内のポータルで検索、リンク登録、安全な表示、再読み込み、モバイル幅などを検証します。同一オリジンを許可した専用の Chrome テストプロファイルを使用してください。テストは対象ブラウザの保存内容を消去するため、日常利用しているプロファイルでは実行しないでください。
- `storage-recovery.html`: 破損した JSON の復旧と、その後の保存を確認します。同様に専用テストプロファイルで実行してください。

JavaScript の構文は JavaScriptCore で `new Function(readFile(path))` により検査できます。
